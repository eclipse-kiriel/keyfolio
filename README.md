# Keyfolio - 커스텀 키보드 & 키캡 빌드 매니저

PC와 안드로이드 스마트폰에서 별도의 플랫폼별 네이티브 빌드 없이 **PWA(Progressive Web App)**로 구동되며, **Google Drive API**를 통해 실시간 클라우드 동기화 및 오프라인 저장을 지원하는 커스텀 키보드/키캡 관리 웹앱입니다.

---

## ✨ 주요 기능

1. **키보드 빌드 스펙 관리**
   - 하우징, 하우징 색상, 마운트 방식, PCB, PCB 타입, 스위치, 스테빌라이저, 장착 키캡 등 기본 프리셋
   - **유연한 동적 옵션 필드**: `+ 옵션 필드 추가` 버튼으로 `하판색상`, `보강판`, `윤활제`, `타건음 링크`, `흡음재 구성` 등 원하는 모든 필드를 자유롭게 추가/삭제
   - **빌드 명세서 원클릭 복사**: 디스코드나 커뮤니티 공유에 최적화된 마크다운 텍스트 복사 지원
2. **키캡 컬렉션 보관함**
   - GMK, ePBT 등 소장 키캡 목록, 프로파일, 재질, 보유 킷, 장착 키보드 자동 연동
3. **구글 클라우드(Firebase) 실시간 동기화**
   - 구글 계정으로 원클릭 로그인
   - PC에서 수정한 내용이 안드로이드 폰에 실시간으로 즉시 반영
   - **오프라인 우선 (Offline-First)**: 인터넷이 끊겨도 로컬에 즉시 저장되고 온라인 시 자동 동기화
4. **로컬 백업 & 복원**
   - 언제든지 JSON 파일로 전체 데이터 다운로드 및 불러오기 가능
5. **PWA (앱 설치 지원)**
   - PC(Chrome/Edge) 및 안드로이드(Chrome)에서 "홈 화면에 앱으로 추가"하여 네이티브 앱처럼 전체화면 구동

---

## 🚀 실행 방법

웹 표준 기술(HTML/CSS/ES Modules)로 제작되어 별도의 복잡한 빌드 과정 없이 바로 실행할 수 있습니다.

### 방법 1: VS Code Live Server 또는 로컬 웹 서버
정적 웹 서버로 폴더를 열어 실행합니다:
```bash
# Python 내장 웹서버 실행 예시 (포트 8080)
python -m http.server 8080
```
브라우저에서 `http://localhost:8080` 으로 접속합니다.

---

## 📱 안드로이드 & PC에 앱으로 설치하기 (PWA)

1. **안드로이드 폰 (Chrome)**:
   - 배포된 웹사이트 URL 또는 로컬 네트워크 IP로 접속
   - 브라우저 상단 우측 메뉴(점 3개) ➡️ **[홈 화면에 추가]** 또는 **[앱 설치]** 선택
   - 홈 화면에 키보드 아이콘의 독립된 앱이 생성됩니다.
2. **PC (Chrome / Edge)**:
   - 주소창 우측의 **[앱 설치] (컴퓨터 모양 아이콘)** 클릭

## ☁️ Google Firebase 클라우드 연동 3분 가이드

앱 상단 우측의 **구름(☁️) 아이콘**을 클릭하여 아래 순서대로 입력하시면 기기 간 실시간 자동 동기화가 활성화됩니다:

1. [Firebase Console](https://console.firebase.google.com/)에 접속하여 **[프로젝트 추가]** (무료)
2. **빌드 ➡️ Authentication ➡️ [시작하기] ➡️ [Google] 공급업체 사용 설정**
3. **빌드 ➡️ Firestore Database ➡️ [데이터베이스 만들기] ➡️ [테스트 모드로 시작]**
4. 프로젝트 개요 우측 **[톱니바퀴 ⚙️ (프로젝트 설정)] ➡️ [내 앱] ➡️ [웹(</>)] 아이콘 클릭**
5. 화면에 나오는 `firebaseConfig` JSON 코드를 복사하여 KeyVault 앱의 **[Firebase 설정]** 창에 붙여넣고 저장
6. **[Google 계정으로 로그인]** 버튼을 누르면 실시간 동기화 완료!
